# Agent collaboration rules

- Read this file and inspect the current worktree before making changes.
- Keep each agent's edits within its explicitly assigned files; coordinate before touching shared files.
- Do not overwrite or revert another agent's uncommitted changes. If work overlaps or conflicts, stop and report it.
- Prefer small, focused changes that follow the existing Astro and Tailwind patterns.
- Run the relevant checks for the files you change and report the exact commands and outcomes.
- Do not commit, push, or change GitHub settings unless the user explicitly asks.
